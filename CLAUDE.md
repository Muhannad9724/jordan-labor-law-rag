# Calude.md 

## Project 
RAG Project for Jordan work law and Social Security law 

Main Goal: Learning how to build RAG projects and have a project to my resume 

## Deployment goal
This project is meant to be launched publicly with a live URL, not just run locally in a notebook — that's the end target, not a stretch goal. Every architecture/tooling choice from here on (embeddings, vector store, backend, hosting) should be made with "can this actually be deployed and stay up cheaply/reliably" in mind, not just "does this work on my machine." Concretely: favor options with a real free/cheap hosting or managed path (e.g. a vector store that has a hosted tier, an embedding approach that doesn't require a dedicated always-on GPU box) over the locally-fastest option when the two conflict; flag the tradeoff explicitly when they do.
